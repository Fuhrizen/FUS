# Setting starter catalogue

150 editable starter entries for a campaign with 6 base HP. These are game abstractions, not manufacturer specifications or playtested balance guarantees. Common damage is 1–2; heavy weapons reach 3. Most armour resists 1, with specialised protection at 2. Dice protection rerolls on each matching component. Imported entries have no hard setting dependency.

Only equipped armour changes calculated HP and speed. Use one body-armour profile at a time: the sheet stacks equipped profiles and does not enforce layering. Item supplies, handling rules, cover, healing and action limits are manual. Test actions only report totals and targets; there is no DC adjudication.

Named Focuses are optional for normal attacks. Specialist actions can require a trained matching Focus; source names resolve under the parent skill when imported. Ranged reloads target self and reset the counter; spare supplies are managed manually.
