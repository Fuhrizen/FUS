# Changelog

All versions before 1.0.0 are beta.

## 0.0.1 — Initial GitHub beta

Imported the supplied FUS 0.0.19 workspace build and reset the GitHub release series to 0.0.1. This is the baseline for future repository updates; historical scratch build numbers are not previous GitHub releases.

- Shared Player/NPC sheets with linked Player and independent NPC token defaults.
- Forms, inventory, skills, Focuses and configurable weapon/Form actions.
- Typed damage, equipped armour adjustments, and Apply Damage / undo.
- Canvas targeting and range preview; custom pooled encounter tracker and 0 HP handling.
- Baseline Form and 150 Medieval, Modern and Sci-Fi starter entries.
- Automated tests, reproducible packages, beta releases, and bug-report template.

Live Foundry validation remains necessary. Automated tests do not establish live UI correctness.
